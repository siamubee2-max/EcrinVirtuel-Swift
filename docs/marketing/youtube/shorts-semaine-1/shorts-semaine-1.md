# Shorts YouTube : semaine 1 (7 Shorts, 1 par jour à 18 h)

Fichiers verticaux 1080 × 1920, de 8 à 14 s, dans ce dossier. Ce sont les mêmes vidéos que sur TikTok et Instagram, publiées **un jour plus tard** pour que chaque plateforme garde un test lisible. Coût : 0 €.

**À chaque Short, dans YouTube Studio :**
1. Cochez **« Contenu modifié ou synthétique »** (étape Détails). Lou est un personnage généré.
2. Public : **« Non, ce contenu n'est pas conçu pour les enfants »**.
3. Après la mise en ligne : commentaire épinglé avec le lien de l'application (voir plus bas).
4. Pas de son à ajouter : les vidéos ont déjà leur son.
