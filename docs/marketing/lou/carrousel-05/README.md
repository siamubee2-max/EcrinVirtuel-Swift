## Version « éditorial » (`edito/`)

Les mêmes six slides existent dans un second style, plus magazine que carnet, dans le dossier `edito/` ([planche](edito/planche.jpg)) :
- la couverture est une photo plein cadre avec un grand titre en serif italique ;
- sur les slides de contenu, la photo est en haut et le texte sur un bandeau encre en bas, pour que la tenue et les bijoux restent visibles ;
- les étiquettes sont en capitales espacées, avec un filet doré ;
- la dernière slide est sur fond encre.

Il n'y a aucune mention d'IA sur les visuels. Pour les régénérer : `python3 scripts/lou-carousel-edito.py 05`.
