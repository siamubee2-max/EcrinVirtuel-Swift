# Carrousel 04 — « 4 couleurs que tu n'oses pas »

Six visuels de 1080 × 1350, dans le style « carnet » des carrousels précédents. Il s'inspire du format éducatif « associations de couleurs », dont un exemple a fait 2,5 M de vues (39,7 fois la médiane de son créateur, @lunah.cal, vidIQ, août 2026).

| # | Contenu |
|---|---|
| 1 | Couverture : « 4 couleurs que tu n'oses pas (et qui marchent vraiment ensemble) », 4 tirages |
| 2 | Violet + gris clair : « raffiné, jamais tristounet » |
| 3 | Rouge + rose : « l'interdit qui fait tourner les têtes » |
| 4 | Vert émeraude + bleu cobalt : « deux couleurs froides, zéro faute » |
| 5 | Moutarde + bordeaux : « l'automne, version chic » |
| 6 | « Laquelle tu oses ? Essaie-les sur toi, en 1 photo. » + « Enregistre ce post » |

Chaque association est accompagnée de pastilles de couleur. La dernière slide demande d'enregistrer le post : sur Instagram, les enregistrements sont un signal fort pour les contenus éducatifs.

## Version « éditorial » (`edito/`)

Les mêmes six slides existent dans un second style, plus magazine que carnet, dans le dossier `edito/` ([planche](edito/planche.jpg)) :
- la couverture est une photo plein cadre avec un grand titre en serif italique ;
- sur les slides de contenu, la photo est en haut et le texte sur un bandeau encre en bas, pour que la tenue et les bijoux restent visibles ;
- les étiquettes sont en capitales espacées, avec un filet doré ;
- la dernière slide est sur fond encre.

Il n'y a aucune mention d'IA sur les visuels. Pour les régénérer : `python3 scripts/lou-carousel-edito.py`.
