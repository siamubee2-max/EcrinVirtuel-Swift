Les présentes conditions régissent l'utilisation de l'application L'Écrin Virtuel, disponible sur l'App Store d'Apple. En téléchargeant ou utilisant l'application, vous acceptez ces conditions.

2. Description du service

L'Écrin Virtuel est une application iOS d'essayage virtuel de bijoux, vêtements et accessoires par intelligence artificielle. Les essayages sont générés à partir de vos photos via les API de Google (Gemini) et OpenAI (GPT Image).
